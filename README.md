# 🚀 Senior JS/TS Automation QA Roadmap (45 Days)

Репозиторий создан для практической отработки навыков и глубокого погружения в JavaScript и TypeScript. Цель — освоение продвинутых концепций языка, архитектуры тест-фреймворков и инфраструктурных решений до уровня Senior AQA / SDET.

## 📊 Прогресс обучения

- **Старт:** 4 августа 2026 г.
- **Текущий прогресс:** [ ] 1% (1/45 дней)
- **Расписание:** 4 часа в день (1.5 часа теория / 2.5 часа практика)

---

## 📅 План по неделям

### 📌 Неделя 1: Фундамент JS (Core & ES6+)

- [x] **День 1:** Области видимости и переменные (`let`, `const`, `var`), поднятие (Hoisting) и временная мертвая зона (TDZ).
- [x] **День 2:** Стрелочные vs Обычные функции, замыкания (Closures) на практике.
- [x] **День 3:** Контекст выполнения (`this`), явная привязка (`.bind()`, `.call()`, `.apply()`).
- [x] **День 4:** Объекты под капотом: копирование по ссылке/значению, поверхностное/глубокое копирование, защита объектов (`Object.freeze`).
- [x] **День 5:** Деструктуризация объектов и массивов, Rest/Spread операторы.
- [x] **День 6:** Практика: Написание модуля динамической конфигурации под разные окружения.
- [x] **День 7:** Выходной / Закрепление пройденного.

### 📌 Неделя 2: Продвинутая работа с данными

- [ ] **День 8:** Трансформация массивов (`.map()`, `.filter()`).
- [ ] **День 9:** Агрегация данных с помощью `.reduce()`.
- [ ] **День 10:** Поиск и проверки в массивах (`.find()`, `.some()`, `.every()`, `.includes()`).
- [ ] **День 11:** Работа со строками и регулярными выражениями (RegExp) для парсинга UI данных.
- [ ] **День 12:** ООП и Классы в JS (наследование, геттеры/сеттеры, статические методы).
- [ ] **День 13:** Практика: Написание парсера и анализатора текстовых логов тестов.
- [ ] **День 14:** Выходной / Закрепление пройденного.

### 📌 Неделя 3: Асинхронный JavaScript

- [ ] **День 15:** Архитектура Event Loop: стек вызовов, очереди макротасок и микротасок.
- [ ] **День 16:** Промисы (Promises): состояния, обработка ошибок, создание кастомных промисов.
- [ ] **День 17:** Работа с группой промисов (`Promise.all()`, `Promise.allSettled()`, `Promise.race()`).
- [ ] **День 18:** Асинхронные функции (`async/await`), тонкости обработки ошибок.
- [ ] **День 19:** Сравнение асинхронных движков в Playwright и Cypress.
- [ ] **День 20:** Практика: Написание кастомного умного ожидания (Smart Waiter) для API/БД.
- [ ] **День 21:** Выходной / Закрепление пройденного.

### 📌 Неделя 4: Node.js и работа с окружением

- [ ] **День 22:** Модули (ESM vs CommonJS), структура проекта в `package.json`, NPM скрипты.
- [ ] **День 23:** Работа с процессами (`process.env`, библиотека `dotenv`, настройка мультиокружения).
- [ ] **День 24:** Модуль `fs/promises` для работы с файлами и сохранения артефактов тестов.
- [ ] **День 25:** Кроссплатформенная работа с путями (модуль `path`, `path.join()`).
- [ ] **День 26:** Сетевые запросы в Node.js (Fetch API, построение базового HTTP-клиента).
- [ ] **День 27:** Практика: Написание скрипта подготовки тестовых данных (API Seeder) перед прогоном тестов.
- [ ] **День 28:** Выходной / Закрепление пройденного.

### 📌 Неделя 5: TypeScript для AQA

- [ ] **День 29:** Введение в TS, типизация, компиляция, настройка `tsconfig.json`.
- [ ] **День 30:** Интерфейсы (`interface`) и типы (`type`) для описания контрактов API.
- [ ] **День 31:** Использование Generics (обобщений) для типизации универсальных методов фреймворка.
- [ ] **День 32:** Utility Types (`Partial`, `Omit`, `Pick`, `Readonly`) для гибкого управления типами.
- [ ] **День 33:** Type Guards (сужение типов) и приведение типов (`as`, `is`).
- [ ] **День 34:** Практика: Полный рефакторинг API-клиента и Page Objects на строгий TS (без `any`).
- [ ] **День 35:** Выходной / Закрепление пройденного.

### 📌 Неделя 6: Архитектурные паттерны и Сеть

- [ ] **День 36:** Реализация паттернов Builder и Factory для генерации сложных тестовых сущностей.
- [ ] **День 37:** Работа с DOM, Shadow DOM и выполнение JS-кода в контексте браузера (`page.evaluate`).
- [ ] **День 38:** Сетевые сессии, CORS-политики в автотестах, декодирование JWT токенов.
- [ ] **День 39:** Автоматизация тестирования протокола WebSockets.
- [ ] **День 40:** Практика: Проектирование сквозного E2E-сценария с обходом формы авторизации по API.
- [ ] **День 41:** Выходной / Закрепление пройденного.

### 📌 Неделя 7: Инфраструктура, Линтинг и CI/CD

- [ ] **День 42:** Статический анализ кода: настройка ESLint, Prettier, автоматизация через Husky git-hooks.
- [ ] **День 43:** Продвинутые фичи тест-раннеров: кастомные фикстуры (Playwright Fixtures), репортеры.
- [ ] **День 44:** CI/CD: Настройка запуска тестов в Docker-контейнере через GitHub Actions.
- [ ] **День 45:** Финальный рефакторинг фреймворка, подведение итогов.

## 🛠️ Стек проекта

- **Runtime:** Node.js (v20+ LTS)
- **Language:** TypeScript / JavaScript (ES6+)
- **Linter & Formatter:** ESLint, Prettier
- **Runner (в будущем):** Playwright

## 📝 Как запустить практические задания

Каждое практическое задание находится в соответствующем файле (например, `day1.js`).
Для запуска используйте команду:

```bash
node day[номер_дня].js
```
